Get used to

The process of becoming accustomed: get used to + noun / -ing.

Alışmak (Süreç)

1Quick Understanding

Get used to, yeni ve başta yabancı/garip gelen bir duruma zamanla alışma SÜRECİNİ anlatır. Türkçedeki "alışıyorum", "alışmaya başladım" ifadelerinin karşılığıdır. Dikkat: buradaki "to" bir edat (preposition) gibi davranır, bu yüzden sonrasına fiil gelecekse mutlaka -ing hâlinde gelir, asla yalın fiil (base verb) gelmez.

2The Structure

Formula

Subject + get / got / getting + used to + noun
Subject + get / got / getting + used to + V-ing
"get" normal bir fiil gibi her zamanda çekimlenir: I get used to..., I got used to..., I'm getting used to..., I've got used to...

Affirmative / Negative / Question

Affirmative

I am getting used to + noun/-ingShe has got used to + noun/-ingI'm getting used to my new job.

Negative

I'm not getting used to + noun/-ingShe hasn't got used to + noun/-ingI'm not getting used to the heat yet.

Question

Are you getting used to + noun/-ing?Has she got used to + noun/-ing?Are you getting used to city life?

Word Order

Özne — get (çekimli) — used to — isim / V-ing

  • I 'm getting used to the noise here.Buradaki gürültüye alışıyorum.
  • They got used to driving on the other side of the road.Yolun diğer tarafında araba kullanmaya alıştılar.

3How It Works

When do we use it?

  • Yeni bir yaşam düzenine alışırken: He's getting used to his new schedule.
  • Yeni bir ülke/kültüre alışırken: We got used to the cold winters after a few years.
  • Yeni bir işe/role alışırken: I'm getting used to working from home.
  • Yeni bir yiyecek/tada alışırken: The kids are slowly getting used to spicy food.
  • Bir eşyaya/nesneye alışırken (isim ile): She's still getting used to her new glasses.

When DON'T we use it?

⚠️
"get used to" sonrasına yalın fiil (base verb) KOYMA — "to" burada edat olduğu için fiil -ing alır.
❌ I'm getting used to drive on the left. → ✅ I'm getting used to driving on the left.
"get used to"yu geçmiş alışkanlıkla (used to) KARIŞTIRMA: ❌ I get used to play tennis every weekend as a child. → ✅ I used to play tennis every weekend as a child.

Short Answers

Kısa cevap, kullanılan zamanın yardımcı fiiline göre verilir: Are you getting used to it? → Yes, I am. / No, I'm not. Have you got used to it? → Yes, I have. / No, I haven't.
Not: "used to" kısmı hiçbir zaman değişmez, sadece "get" çekimlenir.
Türkçe Mantığı

Zihninde şu sırayla ilerle:

TÜRKÇEDE NE DEMEK İSTİYORUM? → "Erken kalkmaya alışıyorum."
↓
BU BİR DEĞİŞİM Mİ, SÜREÇ Mİ? → Evet, önce garipti, şimdi normalleşiyor.
↓
FİİL Mİ GELECEK? → "kalkmak" fiili, "to" bir edat olduğu için -ing alır: waking up
↓
CÜMLE → "I'm getting used to waking up early."

4Examples

Temel

  • I'm getting used to my new phone.Yeni telefonuma alışıyorum.
  • She got used to the silence of the village quite quickly.Köyün sessizliğine oldukça hızlı alıştı.
  • We're getting used to eating dinner later here.Burada akşam yemeğini daha geç yemeye alışıyoruz.
  • He hasn't got used to his new boss yet.Yeni patronuna henüz alışmadı.

Zaman İçinde Değişim

  • It took me months to get used to the traffic in this city.Bu şehirdeki trafiğe alışmam aylar sürdü.
  • You'll get used to studying late at night eventually.Sonunda geceleri geç saatte ders çalışmaya alışacaksın.
  • I've finally got used to wearing glasses.Sonunda gözlük takmaya alıştım.
  • My grandmother never got used to using a smartphone.Büyükannem akıllı telefon kullanmaya hiç alışamadı.

Soru ve Olumsuz

  • Are you getting used to living alone?Yalnız yaşamaya alışıyor musun?
  • Have they got used to the new rules yet?Yeni kurallara henüz alıştılar mı?
  • I'm not getting used to this keyboard at all.Bu klavyeye hiç alışamıyorum.
  • Did you get used to the time difference quickly?Saat farkına hızlıca alıştın mı?

5Compare & Notice

Compare With

Get used to (bu konu)

Bir SÜRECİ anlatır — yabancı bir durum zamanla normalleşiyor, değişim devam ediyor.

I'm getting used to the new system.

VS

Be used to

Bir DURUMU anlatır — artık tamamen alışılmış, değişim bitmiş, o an için normal.

I'm used to the new system now.

→ Used to / Be used to / Get used to üçlü karşılaştırmasına git

6Common Mistakes

❌ I'm getting used to wake up early.
✅ I'm getting used to waking up early.
WHY? "to" burada bir edattır, fiili yalın hâlde değil -ing hâlinde ister.
❌ I get used to play the piano when I was young.
✅ I used to play the piano when I was young.
WHY? Burada anlatılmak istenen geçmişteki bir ALIŞKANLIK, alışma SÜRECİ değil — bu yüzden "used to" (get olmadan) kullanılmalı.
❌ I'm getting used living in a big city.
✅ I'm getting used to living in a big city.
WHY? "to" atlanamaz — yapının olmazsa olmaz bir parçasıdır.
❌ Now I am used to it, I'm still learning everything about it.
✅ I'm still getting used to it — I'm still learning everything about it.
WHY? "am used to" tamamlanmış bir durumu (artık yabancı gelmiyor) anlatır; süreç hâlâ devam ediyorsa "getting used to" kullanılmalı.

10Sık Sorulan Sorular

Get used to ile be used to farkı nedir?

get used to alışma sürecini anlatır (I'm getting used to it = alışıyorum); be used to sonucu (I'm used to it = alışkınım).

Get used to'dan sonra fiil nasıl gelir?

to edattır → -ing: I'm getting used to waking up early.
