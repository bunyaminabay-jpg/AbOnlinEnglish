Second Conditional

Imaginary situations now or in the future: If I had…, I would…

1Quick Understanding

Second conditional, şu an ya da gelecekte gerçek olmayan ya da gerçekleşmesi çok uzak/hayali bir durumu ve onun sonucunu anlatır. "Eğer ... olsaydı, ... olurdu" mantığıdır.

2The Structure

Formula

If + Past Simple, ... would + V1
Tüm şahıslarla "were" kullanımı standarttır: If I were you... / If she were here...

Affirmative / Negative / Question

Affirmative

If I had money, I would travel.

Negative

If I didn't have this job, I wouldn't stay here.

Question

What would you do if you won the lottery?

Word Order

If-clause cümlenin başında ya da sonunda olabilir. Başta ise virgül kullanılır:

  • If I had time, I would help you.If-clause başta → virgül var.
  • I would help you if I had time.If-clause sonda → virgül yok.

3How It Works

When do we use it?

  • Hayali/gerçek dışı şimdiki-gelecek durumlar: If I won the lottery, I would buy a house.
  • Tavsiye vermek (If I were you): If I were you, I would apologize.
  • Gerçekleşmesi çok uzak/olası olmayan durumlar: If I met the president, I would ask him a question.

When DON'T we use it?

⚠️
Gerçekten olması MÜMKÜN bir durum için kullanma — o zaman First Conditional gerekir.
❌ (yarın gerçekten yağmur ihtimali varken) If it rained tomorrow, I would stay home. → ✅ If it rains tomorrow, I will stay home.

Short Answers

Would you help me if I asked? — Yes, I would. / No, I wouldn't.
Türkçe Mantığı

Zihninde şu sırayla ilerle:

TÜRKÇEDE NE DEMEK İSTİYORUM? → "Param olsaydı, dünyayı gezerdim."
↓
BU DURUM GERÇEK Mİ? → Hayır, hayali/olası değil (param yok).
↓
İNGİLİZCEDE HANGİ YAPI? → If + Past Simple, ... would + V1
↓
CÜMLE → "If I had money, I would travel the world."

4Examples

  • If I had more time, I would learn to play the piano.Daha çok zamanım olsa piyano çalmayı öğrenirdim.
  • If I were you, I would talk to her.Senin yerinde olsam onunla konuşurdum.
  • She would travel more if she had enough money.Yeterince parası olsa daha çok seyahat ederdi.
  • If we lived closer, we would see each other more often.Daha yakın yaşasak daha sık görüşürdük.
  • What would you do if you saw a ghost?Bir hayalet görsen ne yapardın?
  • If I won the lottery, I would buy a house by the sea.Piyangoyu kazansam deniz kenarında bir ev alırdım.
  • He wouldn't say that if he knew the truth.Gerçeği bilse bunu söylemezdi.

5Compare & Notice

Compare With: Second vs Third Conditional

Second Conditional

Şimdiki/gelecekteki hayali durum.

If I had money, I would travel. (şu an param yok)

VS

Third Conditional

Geçmişte gerçekleşmemiş durum + pişmanlık.

If I had had money, I would have traveled. (geçmişte param yoktu)

Visual: Gerçek Dünya vs Hayali Dünya

ŞİMDİ
GERÇEK DÜNYA: I don't have money → I don't travel.
HAYALİ DÜNYA (Second Conditional): If I had money → I would travel.

6Common Mistakes

❌ If I would have money, I would travel.
✅ If I had money, I would travel.
WHY? "Would" if-clause içine KONMAZ — if-clause'da sadece Past Simple kullanılır.
❌ If I would go there, I would tell you.
✅ If I went there, I would tell you.
TÜRKÇE MANTIK: Türkçede iki tarafta da "-sa/-se" hissi olduğu için "would" ikinci yarıya değil sadece sonuç cümlesine ait olduğunu unutmamak gerekir.
❌ If I had a car, I would went to the beach.
✅ If I had a car, I would go to the beach.
WHY? "Would" dan sonra V1 (yalın fiil) gelir, V2 değil.

10Sık Sorulan Sorular

If'li kısımda would kullanılır mı?

Hayır: If I had money, I would travel. (If I would have ❌)

"If I was you" mı "If I were you" mu?

Tavsiye kalıbında standart biçim If I were you'dur. Günlük konuşmada was de duyulur, ama sınavlarda were beklenir.
