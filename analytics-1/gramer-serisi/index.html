Bu seri nasıl kullanılır?

Her seviye kendi sayfasında; konu başlıkları, kısa kural anlatımı, formül tablosu, olumlu/olumsuz/soru cümle örnekleri, sık yapılan hatalar ve mini alıştırmalarla tek bir görselde sunulur. Kartlara tıklayarak sayfayı büyük boyutta inceleyebilir, arama kutusuyla aradığınız konuyu saniyeler içinde bulabilirsiniz.

Seri; sınıf içi kullanım, ödev/tekrar materyali, öz-öğrenim ve sosyal medya paylaşımları için tasarlanmıştır.

  • A1 — Başlangıç: Temel yapılar (to be, present simple, can/can't). A1 serisine git →
  • A2 — Temel: Geçmiş zamanlar, koşul cümleleri, dolaylı anlatım. A2 serisine git →
  • B1 — Orta: Edilgen çatı, ikinci koşul, wish yapısı. B1 serisine git →
  • B2 — Orta-Üstü: Inversion, cleft sentence, akademik kelime bilgisi. B2 serisine git →
